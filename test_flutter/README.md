# Greeting App

This is a Flutter Material 3 greeting app. It uses only Flutter SDK packages.

## Run on Windows from VS Code

Install the Flutter SDK and the Flutter extension for VS Code. Open this
`test_flutter` folder, then run these commands in its terminal:

```powershell
flutter create --platforms=windows .
flutter pub get
flutter run -d windows
```

The first command generates the Windows desktop runner for this project. After
that, select **Greeting App (Windows)** in VS Code's Run and Debug panel or
press F5.
